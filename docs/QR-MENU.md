# QR-меню ресторана (`/menu`)

Страница для QR-кода на столах: афиша (баннер из «Настройки») → картинка обеденного меню на день. **Заказа нет** — только просмотр + кнопка «Заказать с доставкой» на `/`.

## Что не трогаем

- Excel-меню, слоты обеда, десерт, корзина, уведомления заказов — без изменений.
- Баннер остаётся один (`banner-azure` в Настройках). QR его только показывает.

## Файлы Dropbox

| День | Имя файла |
|------|-----------|
| Пн–Пт | `menu-azure-1` … `menu-azure-5` (+ расширение) |

Админка → вкладка **QR-меню**: загрузка/замена по дням (тот же dropbox API, что баннер).

## Локальная проверка

1. `http://localhost:3000/menu` — афиша (если включена) → вкладки Пн–Пт.
2. Админ → QR-меню — загрузить тестовые картинки.
3. Главная `/` и десерт — поведение как до QR.
